# Maison Aegis

Classic royal cybersecurity roadmap — from Apprentice to Sovereign.

**Live:** Open `index.html` or use GitHub Pages / Netlify / Vercel.

## Features
- Sign up for weekly email (+ optional WhatsApp)
- Earn rank via 12-question assessment (videos unlock after)
- Feedback after 10 minutes on site
- Royal luxury design

## Local server
```bash
node server/index.js
# http://localhost:3847
```
